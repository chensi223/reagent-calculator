# 参考项目评估：Huozqi/Reagent-Mass-Calculator

> 2026-09-29 评估。来源：https://github.com/Huozqi/Reagent-Mass-Calculator （MIT 许可）
> 取用方式：GitHub 直连超时，**走 jsdelivr CDN 拿到**（`https://cdn.jsdelivr.net/gh/<owner>/<repo>@main/<file>`）

## 它是什么

RMC（Reagent Mass Calculator）—— Python + tkinter/customtkinter 的 Windows 桌面投料计算器。

- `RMC.py`（1018 行）—— 主程序
- `reagents_db.csv`（1.6 MB / 15,327 行）—— 本地试剂库
- CSV 字段：`SMILES, CAS_ref, Name, Density, UNIT, INCHI_KEY, CAS, MW`

功能：底物参数（名称/分子量/投料质量/含量）→ 试剂清单（名称/分子量/密度/含量/当量）→ 自动算质量/体积/mmol；支持按 CAS 或 Name 从 CSV 查库填充；装了 RDKit 可画结构式。

## 一、数据：MW 可用，密度不可靠

### MW —— 质量好

与本项目词典（313 条）按 CAS 比对，**162 条重合，MW 偏差 >0.05 的 0 条**。

### ★ 密度 —— 不能直接用

141 条可比对，**21 条差异 >3%**，其中多条是明显错误：

| 试剂 | 本项目词典 | 该 CSV | 真值 | 谁对 |
|---|---|---|---|---|
| 甲苯 | 0.872 | **0.94** | 0.867 | 词典 |
| 硝酸钾 | 2.109 | **1.0** | 2.109 | 词典 |
| 四氧化锇 | 4.906 | **1.04** | 4.9 | 词典 |
| 二环己基碳二亚胺 | 1.247 | 1.06 | ~1.25 | 词典 |
| N-氯代丁二酰亚胺 | 1.65 | 1.5 | — | 存疑 |
| 4-二甲氨基吡啶 | 0.906 | 1.012 | — | CSV 更可能对 |
| 草酸 | 1.772 | 1.9 | 无水 1.90 | CSV 更可能对 |

**结论：两边密度都不可靠** —— 这正是本项目把密度设计成「给候选让用户点选确认」而不是自动填死的原因。

### 只有英文名，没有中文名

CSV 的 `Name` 全为英文（Benzaldehyde、Acetonitrile…）。而本项目要解决的核心恰恰是**中文名查询**（已由百度百科 JSONP 覆盖 95%）。所以这个库对中文场景帮助有限。

### 体量

15,327 行 / 1.6 MB。全部内嵌会把单文件程序从 327 KB 撑到 2 MB 左右，与「双击即用的轻量单文件」定位冲突。

## 二、代码：没有可直接复用的部分

| | 它 | 本项目 |
|---|---|---|
| 查询 | 线性遍历 15,327 条，子串匹配，**取第一个命中** | 建 Map 索引 + 归一化键 + 多字段（中文名/别名/英文名/缩写/CAS/分子式） |
| 计算 | **单向**：底物质量 → 其余全部；纯度按小数（0–1） | **双向约束传播**：任填一部分（含反算、产物反推）；纯度按百分比 |
| 平台 | Python + tkinter，需装 Python/customtkinter/RDKit | 单 HTML 文件，零依赖 |

它的核心计算代码：

```python
base_mmol = base_mass_g * base_purity / base_mw * 1000
mass_g    = current_mmol * mw / 1000 / purity     # 称量质量 = 理论质量 / 含量
vol_mL    = mass_g / density
```

**这套公式与本项目完全一致** —— 算是独立确认了本项目的纯度折算与体积换算没写错。

## 三、结论

**没有值得直接搬进来的东西。**

- 密度不能用（会引入错误）
- 无中文名（正是本项目要解决的）
- 体量太大（1.6 MB）
- 代码逻辑比本项目简单（线性查、单向算）

**可以留作后用的两点**：

1. 它的 `SMILES` + `INCHI_KEY` 字段覆盖了 15,327 条化合物。若将来要做「结构式输入/显示」，这批数据是一份现成的 SMILES 来源（无需联网）。
2. 若将来需要**离线英文名查询**（比如断网时查一个冷门英文名），可以把 CSV 精简成 `CAS|Name|MW` 三列（约 400 KB），做成可选的扩展词典文件，由用户在「词典管理 → 导入 JSON」按需加载。**当前不做** —— 保持单文件轻量。

```

```

以后遇到 GitHub 拉不动的情况，**先用 jsdelivr 试**。注意它只能取仓库里的文件，不能 clone 整个仓库（对本次需求够用）。
